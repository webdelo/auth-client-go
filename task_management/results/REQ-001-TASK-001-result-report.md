## Summary

Зафиксированы три direct-зависимости SDK (`github.com/webdelo/auth-proto/go@v0.1.0`, `google.golang.org/grpc@v1.79.3`, `golang.org/x/sync@v0.19.0`) в `go.mod`. README обновлён разделом «Local integration testing».

## Deviations from PRP

1. **`go 1.24.0` vs `go 1.24`**: Go's `go mod tidy` auto-formats to `go MAJOR.MINOR.PATCH`. Same minor version — within PRP intent ("downgrade from 1.26.2 to 1.24").
2. **`grpc v1.79.3`, `x/sync v0.19.0`**: MVS-resolved from `auth-proto/go@v0.1.0` transitives. Matches PRP statement ("MVS from auth-proto/go transitive").
3. **3 blank imports** in `lib/client_integration_test.go` instead of 1: needed to keep ALL three direct dependencies pinned (PRP DOD requires `go mod why` direct for all three; singleflight-only blank import was insufficient because `go mod tidy` pruned the other two transitives).
4. **`GOLANGCI_VERSION` bumped `v1.64.8` → `v2.11.4`**: pre-existing infra mismatch (`.golangci.yaml` was already v2 format from bootstrap commit). DOD requires `make audit` to pass cleanly — bumping was the minimum fix.
