# Refresh Context

Context may have been lost or compressed. Restore it.

## 1. Steps

1. Re-read `.memory_bank/README.md` completely.
2. Study current tasks in `.memory_bank/current_tasks.md`.
3. Review recent code changes.

## 2. Output

Print "Context updated" and brief current project status with active tasks.

## 3. Related Commands

- `/refresh-memory-bank` — full memory bank refresh.
- `/refresh-agents` — update .claude/AGENTS.yaml.
- `/refresh-req-status` — update task statuses.
