# Claude Agents

This directory contains configuration for Claude Code agents.

## Available Agents

Agents are specialized for different tasks:

- **code-reviewer** - Code review and quality checks
- **unit-test-writer** - Writing unit tests
- **debugger** - Debugging and error fixing
- **doc-generator** - Documentation generation

## Usage

Agents are invoked automatically by Claude Code when needed.

## Configuration

Agent definitions are in the `agents/` subdirectory.
Commands are in the `commands/` subdirectory.
